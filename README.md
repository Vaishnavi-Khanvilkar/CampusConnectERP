# CampusConnect ERP – Student Activity Management Portal

CampusConnect ERP is a dynamic web-based Student Activity Management Portal developed as an internship project. The system provides a centralized platform for managing various student and academic activities such as attendance, assignments, notices, events, and user information.

---

## 📌 Project Overview

Managing student activities manually can be time-consuming and difficult to maintain. CampusConnect ERP provides a centralized digital platform that helps students, teachers, and administrators manage and access academic information efficiently.

The application provides different modules according to the user's role, making the system organized, user-friendly, and easy to manage.

---

## 🎯 Objectives

The main objectives of CampusConnect ERP are:

- To develop a centralized student activity management system.
- To manage student attendance digitally.
- To manage assignments and due dates.
- To publish and display important notices.
- To manage academic events.
- To provide separate modules for students, teachers, and administrators.
- To store and retrieve information using a database.
- To provide a responsive and user-friendly interface.
- To gain practical experience in dynamic web application development.

---

## 👥 User Roles

### 👨‍🎓 Student

Students can:

- Login to their account
- Access the student dashboard
- View profile information
- View attendance
- Check attendance percentage
- View assignments
- Check assignment due dates
- View notices
- View events
- Manage password

### 👨‍🏫 Teacher

Teachers can:

- Login to the teacher dashboard
- Manage assignments
- Manage notices
- Manage events
- View student-related information
- Manage their profile

### 👨‍💼 Administrator

Administrators can:

- Access the admin dashboard
- Manage students
- Manage teachers
- Manage notices
- Manage events
- Manage system information
